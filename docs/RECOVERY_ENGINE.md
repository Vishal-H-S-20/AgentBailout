## AgentBailout 4.0 Phase A/B checkpoint

The existing watchdog, compatible replacement pool, economic policy and immutable input reuse remain. Real provider errors are classified and routed through bounded recovery. A real-provider stage cannot recover through an offline candidate. Cross-provider backup must be explicitly selected in the recovery pool. Same-model retries and safe configuration repair are not newly claimed implemented.
